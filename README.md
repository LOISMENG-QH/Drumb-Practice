# 架子鼓节奏练习生成器

4/4 拍三行五线谱（右手 ✕ / 左手 ● / 右脚 ●）的节奏练习工作台。单文件、零依赖、离线可用。

## 功能

- 🎲 随机生成：16 种基本节奏型（0、1、2、3、4、12、13、14、23、24、34、123、124、134、234、1234）每个声部 × 每小节独立随机组合
- ✏️ 自定义：点击谱面任意节拍位置即可开/关音符
- ▶ 试听：Web Audio 合成鼓组（踩镲/军鼓/底鼓）+ 节拍器 + 播放头高亮
- 💾 保存/加载：浏览器 localStorage 练习库
- ⬇️⬆️ 导入/导出 JSON 跨设备迁移
- 🖨 打印谱面

## 使用

直接打开 [在线版](https://loismeng-qh.github.io/drum-practice/) 或双击 `index.html`。

快捷键：`空格` 播放/停止 · `R` 随机 · `C` 清空
